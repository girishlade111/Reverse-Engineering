PROJECT IDENTITY
========================================================================

Project Name:       Enterprise Reverse Engineering Prompt Framework
Project Acronym:    EREPF
Version:            3.0
Classification:     Internal Enterprise Framework
Domain:             Software Reverse Engineering / AI Prompt Engineering
Framework Type:     Modular Multi-Phase Prompt Orchestration System

========================================================================
SCOPE
========================================================================

IN SCOPE:
- Complete software repository reverse engineering
- Architecture discovery and documentation
- Module and component deep analysis
- Data flow and state management extraction
- Business logic and domain model reconstruction
- AI workflow and automation pipeline analysis
- Integration and dependency mapping
- Security and error handling auditing
- Comprehensive documentation generation
- Quality validation and cross-referencing

OUT OF SCOPE:
- Modifying the target repository
- Fixing bugs in the target repository
- Decompiling obfuscated or encrypted binaries
- Runtime analysis requiring execution of the target
- Network traffic analysis of the running system
- User behavior analysis
- Performance benchmarking

========================================================================
TARGET REPOSITORY REQUIREMENTS
========================================================================

Supported:
- Any programming language source code
- Multi-language repositories
- Mono-repositories
- Microservice architectures
- AI/Agent frameworks
- Web applications
- Mobile applications
- Backend services
- Libraries and frameworks
- CLI tools
- Database scripts and schemas
- Infrastructure as Code
- Configuration files
- Documentation repositories

NOT Supported:
- Fully obfuscated code without source access
- Compiled-only binaries without source
- Hardware description languages (VHDL, Verilog)
- Quantum computing circuits
- DNA computing sequences
