========================================================================
SUPPLEMENTARY PROMPT S5: BUILD AND CI ANALYSIS
========================================================================
Supplementary Analysis: Build System, CI/CD, and Automation
Enterprise Reverse Engineering Prompt Framework

========================================================================
PURPOSE
========================================================================

This supplementary prompt provides deep analysis of the build
system, CI/CD pipelines, and automation infrastructure beyond
what is covered in the standard phases.

========================================================================
WHEN TO USE
========================================================================

Execute this prompt if:
- Build system is complex or custom
- Multiple build configurations exist
- CI/CD pipeline is complex or multi-stage
- Infrastructure as Code is significant
- Deployment automation is elaborate

Execute after Phase 7 and before Phase 9.

========================================================================
ACTIVITIES
========================================================================

S5.1. BUILD SYSTEM ANALYSIS
- Document build tool and configuration
- Document build targets and variants
- Document build optimization (caching, parallel)
- Document dependency resolution and locking
- Document build scripts and generators

S5.2. CI/CD PIPELINE ANALYSIS
- Document pipeline stages and their purposes
- Document trigger conditions and schedules
- Document artifact management
- Document environment promotion strategy
- Document approval gates and checks

S5.3. INFRASTRUCTURE AS CODE ANALYSIS
- Document IaC tool and configuration
- Document environment definitions
- Document resource provisioning
- Document configuration management
- Document secret management

S5.4. AUTOMATION ANALYSIS
- Document pre-commit hooks and linting
- Document code generation scripts
- Document database migration automation
- Document release automation
- Document notification/monitoring automation

========================================================================
REQUIRED ARTIFACTS
========================================================================

ARTIFACT S5.1: BUILD_SYSTEM.md
ARTIFACT S5.2: CI_CD_PIPELINE.md
ARTIFACT S5.3: INFRASTRUCTURE_CODE.md
ARTIFACT S5.4: AUTOMATION_SCRIPTS.md

END OF PROMPT S5
