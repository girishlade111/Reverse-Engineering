SUPPLEMENTARY PROMPT S9: OBSERVABILITY ANALYSIS
========================================================================
Supplementary Analysis: Observability, Telemetry, and Monitoring
Enterprise Reverse Engineering Prompt Framework

========================================================================
PURPOSE
========================================================================

This supplementary prompt provides deep analysis of the
observability infrastructure: logging, metrics, tracing,
alerting, and dashboard configuration.

========================================================================
WHEN TO USE
========================================================================

Execute this prompt if:
- Structured logging is used
- Metrics collection exists (Prometheus, StatsD, etc.)
- Distributed tracing is implemented
- Alerting rules are defined
- Monitoring dashboards are configured
- APM tools are integrated

Execute after Phase 8.

========================================================================
ACTIVITIES
========================================================================

S9.1. LOGGING INFRASTRUCTURE
- Document logging library and configuration
- Document log levels and their usage patterns
- Document structured log field schemas
- Document log aggregation and storage
- Document log retention and search

S9.2. METRICS ANALYSIS
- Document metrics library and configuration
- Catalog all custom metrics and their purposes
- Document metric naming conventions
- Document metric cardinality and performance impact
- Document metric visualization (dashboards)

S9.3. DISTRIBUTED TRACING
- Document tracing library and configuration
- Document trace context propagation
- Document span naming conventions
- Document sampling strategy
- Document trace visualization and analysis

S9.4. ALERTING ANALYSIS
- Document alert rules and their thresholds
- Document alert severity levels
- Document notification channels
- Document on-call/escalation procedures
- Document runbooks linked to alerts

ARTIFACT S9.2: METRICS_CATALOG.md
ARTIFACT S9.3: TRACING_ARCHITECTURE.md
