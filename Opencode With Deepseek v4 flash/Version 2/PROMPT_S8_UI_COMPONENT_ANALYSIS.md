SUPPLEMENTARY PROMPT S8: UI COMPONENT ANALYSIS
========================================================================
Supplementary Analysis: User Interface Component Architecture
Enterprise Reverse Engineering Prompt Framework

========================================================================
PURPOSE
========================================================================

This supplementary prompt analyzes the UI component architecture,
component tree, rendering patterns, and UI state management.

========================================================================
WHEN TO USE
========================================================================

Execute this prompt if:
- The system has a graphical user interface
- UI component libraries/frameworks are used
- Complex component hierarchies exist
- UI state management is significant
- Component patterns need documentation

Execute after Phase 3.

========================================================================
ACTIVITIES
========================================================================

S8.1. COMPONENT TREE ANALYSIS
- Document root component and hierarchy
- Document page/route component structure
- Document shared/reusable components
- Document component composition patterns
- Document layout and container components

S8.2. UI STATE MANAGEMENT
- Document UI state management approach
- Document form state management
- Document navigation state
- Document UI context providers
- Document UI state persistence

S8.3. RENDERING PATTERNS
- Document server-side vs client-side rendering
- Document lazy loading patterns
- Document virtual scrolling / windowing
- Document animation and transition patterns
- Document conditional rendering strategies

S8.4. STYLING ARCHITECTURE
- Document CSS/styling methodology
- Document design system / component library
- Document theme and customization approach
- Document responsive design strategy
- Document accessibility patterns

ARTIFACT S8.2: UI_STATE_MANAGEMENT.md
ARTIFACT S8.3: RENDERING_PATTERNS.md
ARTIFACT S8.4: STYLING_ARCHITECTURE.md
