Supplementary Analysis: Data Migration and ETL Pipelines
Enterprise Reverse Engineering Prompt Framework

========================================================================
PURPOSE
========================================================================

This supplementary prompt analyzes data migration processes,
ETL/ELT pipelines, data transformation scripts, and schema
migration strategies.

========================================================================
WHEN TO USE
========================================================================

Execute this prompt if:
- Database migration files/folders exist
- ETL/ELT pipeline code exists
- Data import/export scripts exist
- Data transformation pipelines are present
- Schema versioning is managed

Execute after Phase 7.

========================================================================
ACTIVITIES
========================================================================

S14.1. MIGRATION INFRASTRUCTURE
- Document migration framework/tool
- Document migration file organization
- Document migration execution order
- Document migration rollback strategy
- Document migration testing approach

S14.2. SCHEMA EVOLUTION HISTORY
- Document schema changes over time
- Document data backfill processes
- Document data transformation during migration
- Document data integrity verification
- Document zero-downtime migration patterns

S14.3. ETL/ELT PIPELINE ANALYSIS
- Document pipeline sources and destinations
- Document transformation steps and logic
- Document scheduling and triggering
- Document error handling and data quality checks
- Document pipeline monitoring
