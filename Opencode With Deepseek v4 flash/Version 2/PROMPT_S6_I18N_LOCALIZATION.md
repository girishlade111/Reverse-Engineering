SUPPLEMENTARY PROMPT S6: I18N AND LOCALIZATION
========================================================================
Supplementary Analysis: Internationalization and Localization
Enterprise Reverse Engineering Prompt Framework

========================================================================
PURPOSE
========================================================================

This supplementary prompt analyzes internationalization (i18n)
and localization (l10n) patterns in the system.

========================================================================
WHEN TO USE
========================================================================

Execute this prompt if:
- The system supports multiple languages/locales
- i18n libraries or frameworks are used
- Locale-specific formatting exists
- Translation files or services are present
- Multi-region deployment support exists

Execute after Phase 4.

========================================================================
ACTIVITIES
========================================================================

S6.1. I18N INFRASTRUCTURE ANALYSIS
- Document i18n library and configuration
- Document locale detection and selection
- Document translation storage and retrieval
- Document fallback chain strategy
- Document right-to-left (RTL) support

S6.2. TRANSLATION CATALOG
- Document locale/language inventory
- Document translation coverage per locale
- Document translation management workflow
- Document dynamic/variable content handling
- Document pluralization and gender rules

S6.3. LOCALIZATION FORMATTING
- Document date/time formatting
- Document number/currency formatting
- Document address/name formatting
- Document sorting/collation rules

ARTIFACT S6.2: TRANSLATION_CATALOG.md
ARTIFACT S6.3: LOCALIZATION_FORMATTING.md
