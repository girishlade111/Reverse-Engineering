## OUTPUT EXPECTATIONS

For each prompt, you must produce:

### Required Outputs

- **Analysis Results**: Complete answers to all prompt questions
- **Evidence References**: Specific file paths and line numbers
- **Diagrams**: Mermaid/UML diagrams where applicable
- **Lists**: Inventories, catalogs, and enumerations
- **Mappings**: Relationship and dependency mappings

### Optional Outputs (When Applicable)

- **Code Examples**: Illustrative code snippets
- **Comparisons**: Alternative approach comparisons
- **Recommendations**: Improvement suggestions
- **Warnings**: Identified risks or issues

### Format Requirements

- Use Markdown formatting throughout
- Include mermaid diagrams for visual representations
- Use tables for structured data
- Provide clear section headers
- Include cross-references to related analysis

## ERROR HANDLING

### If You Encounter Ambiguity

1. Document the ambiguity explicitly
2. List possible interpretations
3. Note which interpretation you're assuming
4. Flag for human review if critical

### If You Cannot Access Files

1. Document which files are inaccessible
2. Explain impact on analysis
3. Proceed with available information
4. Note gaps in final report

### If Analysis Reveals Inconsistencies

1. Document the inconsistency
2. Investigate possible causes
3. Note in appropriate section
4. Include in final summary
