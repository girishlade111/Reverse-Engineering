\## 📝 \*\*PROMPT MODULES (11 Total)\*\*



Each prompt module follows the standard template. Here are the \*\*objectives\*\* for each:



\---



\### \*\*PROMPT\_01\_REPOSITORY\_ANALYSIS.md\*\*

\*\*Objective:\*\* Initial repository scan and structural analysis

\- Scan all files recursively

\- Categorize every file by type

\- Calculate statistics (LOC, file count, languages)

\- Identify all entry points

\- Detect build system and configuration

\- Extract package metadata

\- Generate folder structure diagram



\---



\### \*\*PROMPT\_02\_ARCHITECTURE\_DISCOVERY.md\*\*

\*\*Objective:\*\* Discover complete architecture

\- Analyze folder structure for clues

\- Detect architecture patterns (MVC, Microservices, Hexagonal, Clean, etc.)

\- Identify layer boundaries

\- Map module relationships

\- Document architectural decisions

\- Generate architecture diagrams



\---



\### \*\*PROMPT\_03\_DEPENDENCY\_MAPPING.md\*\*

\*\*Objective:\*\* Build complete dependency graph

\- Parse all import/require statements

\- Resolve all import targets

\- Build bidirectional dependency graph

\- Detect all circular dependencies

\- Categorize dependencies (internal/external, direct/transitive)

\- Calculate dependency metrics

\- Generate dependency diagrams



\---



\### \*\*PROMPT\_04\_CODE\_STRUCTURE\_ANALYSIS.md\*\*

\*\*Objective:\*\* Parse all code structure using AST

\- Parse every source file

\- Extract all classes, functions, interfaces, types

\- Build inheritance hierarchies

\- Map all function calls

\- Detect code duplication

\- Identify design patterns

\- Generate class hierarchy and call graph diagrams



\---

\### \*\*PROMPT\_05\_EXECUTION\_FLOW\_MAPPING.md\*\*

\*\*Objective:\*\* Trace all execution paths

\- Trace from every entry point

\- Map all control flow (conditionals, loops)

\- Document all error handling paths

\- Analyze state transitions

\- Trace async operations

\- Generate sequence diagrams



\---

\### \*\*PROMPT\_06\_STATE\_MANAGEMENT\_ANALYSIS.md\*\*

\*\*Objective:\*\* Analyze all state management

\- Identify all state variables

\- Track all state changes

\- Map all state transitions

\- Identify state machines

\- Analyze state persistence

\- Analyze state synchronization

\- Generate state machine diagrams



\---

\### \*\*PROMPT\_07\_API\_INTEGRATION\_ANALYSIS.md\*\*

\*\*Objective:\*\* Document all API and service integrations

\- Identify all API endpoints

\- Document all service integrations

\- Map all middleware components

\- Document all external API calls

\- Generate integration diagrams



\---

\### \*\*PROMPT\_08\_AI\_WORKFLOW\_ANALYSIS.md\*\*

\*\*Objective:\*\* Analyze AI-specific workflows

\- Identify all prompt definitions

\- Map all agent interactions

\- Document reasoning processes

\- Trace planning pipelines

\- Document tool integrations

\- Analyze memory/RAG/search/streaming workflows



\---

\### \*\*PROMPT\_09\_DOCUMENTATION\_GENERATION.md\*\*

\*\*Objective:\*\* Generate comprehensive documentation

\- Generate all architecture documentation

\- Generate all structural documentation

\- Generate all behavioral documentation

\- Generate all code documentation

\- Generate all relationship documentation

\- Ensure 100% completeness



\---

\### \*\*PROMPT\_10\_VALIDATION\_VERIFICATION.md\*\*

\*\*Objective:\*\* Validate all analysis

\- Run all quality standards checks

\- Verify completeness (100% coverage)

\- Verify accuracy (spot-check)

\- Verify consistency

\- Generate validation report

\### \*\*PROMPT\_11\_CROSS\_REFERENCE\_GENERATION.md\*\*
