# MISSION: COMPREHENSIVE SOFTWARE REVERSE ENGINEERING

## Core Objective

To design and execute a world-class Reverse Engineering Prompt Framework that enables any AI coding agent to **completely** reverse engineer **any** software repository with **maximum** technical accuracy, engineering depth, and documentation quality.

## Primary Mission

The framework must empower AI agents to:

1. **Fully Comprehend** any software system from source code alone
2. **Accurately Reconstruct** the complete architecture, workflows, and logic
3. **Precisely Document** every component, relationship, and decision
4. **Maintain** engineering rigor and production-grade quality
5. **Scale** to repositories of any size and complexity

## Non-Negotiable Principles

- **NO SHORTCUTS**: Complete understanding is mandatory before documentation
- **NO ASSUMPTIONS**: Every fact must be verified from source code
- **NO OMMISSIONS**: Every component, flow, and relationship must be captured
- **NO SIMPLIFICATIONS**: Complexity must be preserved, not reduced
- **NO LIMITATIONS**: The framework must handle any technology stack

## Success Criteria

The framework succeeds when an AI agent can:

- Rebuild the entire system from documentation alone
- Explain every line of code's purpose and relationships
- Trace any execution path from start to finish
- Identify every design pattern and engineering decision
- Generate production-ready documentation for any audience

## Scope Definition

### IN SCOPE

- All source code files
- All configuration files
- All build scripts
- All dependencies
- All external integrations
- All internal relationships
- All execution paths
- All state transitions
- All error handling
- All design patterns
- All engineering decisions

### OUT OF SCOPE

- User data
- Runtime secrets
- External system implementations
- Business requirements (unless embedded in code)
- Non-technical documentation

## Quality Mandate

Every output must meet **enterprise production standards**:

- Technically accurate
- Completely comprehensive
- Perfectly consistent
- Professionally structured
- Infinitely maintainable
